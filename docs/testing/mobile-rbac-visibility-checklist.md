# 移动端 RBAC 页面级可见性测试清单

## 1. 目标与范围

本清单用于移动端 RBAC 的页面级可见性验证，覆盖：

- 登录后菜单与路由可见性
- 页面入口权限过滤
- 关键操作按钮显隐
- 刷新/重进后的权限状态

本轮按“移动端功能可少一些”的约束，优先验证权限适配链路，不强行覆盖全部后台管理复杂交互。

## 2. 测试账号

- `super_super`：超管，全权限
- `rbac_user_manager`：管理权限
- `rbac_readonly`：只读权限

若缺账号，对应用例可记为 `blocked`，不算功能失败。

## 3. 执行前检查

- 已完成登录并拿到 token
- 登录返回包含以下任一结构并可被前端兼容：
  - `permissionContext`
  - `menuInfoVoList` + `roleInfoVo/roleInfoVoList` + `orgInfoVo`
- 路由守卫生效：未登录访问受保护路由会跳转登录页

## 4. 页面级可见性用例

## 4.1 权限链路基础

- [ ] `M-RBAC-001` 未登录访问受保护页面
  - 步骤：直接访问业务路由（非 `/login`）
  - 断言：跳转到登录页

- [ ] `M-RBAC-002` 超管登录后动态路由注入
  - 角色：`super_super`
  - 步骤：登录 -> 进入“我的/用户域相关入口”
  - 断言：可访问授权页面，不出现 404

- [ ] `M-RBAC-003` 只读角色菜单过滤
  - 角色：`rbac_readonly`
  - 步骤：登录 -> 浏览用户域入口
  - 断言：仅显示授权页面入口，未授权入口不可见

- [ ] `M-RBAC-004` 刷新后权限状态保持
  - 角色：`rbac_user_manager`
  - 步骤：进入已授权页 -> 刷新
  - 断言：不回登录、不 404、仍可访问

## 4.2 用户域页面入口

- [ ] `M-RBAC-101` 菜单管理页面入口可见性
  - 步骤：进入用户域 -> 查找“菜单管理”入口
  - 断言：有权限角色可见，无权限角色不可见

- [ ] `M-RBAC-102` 权限管理页面入口可见性
  - 步骤：进入用户域 -> 查找“权限管理”入口
  - 断言：有权限角色可见，无权限角色不可见

- [ ] `M-RBAC-103` 角色管理页面入口可见性
  - 步骤：进入用户域 -> 查找“角色管理”入口
  - 断言：有权限角色可见，无权限角色不可见

- [ ] `M-RBAC-104` 机构管理页面入口可见性
  - 步骤：进入用户域 -> 查找“机构管理”入口
  - 断言：有权限角色可见，无权限角色不可见

## 4.3 关键按钮显隐（页内）

- [ ] `M-RBAC-201` 只读角色无新增/编辑/删除入口
  - 角色：`rbac_readonly`
  - 页面：菜单/权限/角色/机构
  - 断言：页内不可见新增、编辑、删除入口

- [ ] `M-RBAC-202` 超管具备配置域操作入口
  - 角色：`super_super`
  - 页面：菜单/权限/角色/机构
  - 断言：页内可见新增、编辑、删除等核心入口

- [ ] `M-RBAC-203` 机构管理页面无用户绑定入口
  - 页面：机构管理
  - 断言：不存在“新增用户/移动用户/分配用户”入口

## 4.4 路由与容错

- [ ] `M-RBAC-301` 非法路由处理
  - 步骤：访问不存在路由
  - 断言：进入 404 页面

- [ ] `M-RBAC-302` 动态路由重复注入保护
  - 步骤：登录后多次进出页面
  - 断言：无重复路由报错，页面可正常切换

- [ ] `M-RBAC-303` 菜单缺少 permissionCode 的兼容
  - 前置：存在未配置 `permissionCode` 的菜单项
  - 断言：该菜单按当前策略可正常访问（默认放行）

## 5. 结果记录模板

```md
- [ ] CASE: M-RBAC-xxx
  - 角色:
  - 页面:
  - 结果: pass / fail / blocked
  - 证据: 截图路径
  - 备注:
```

## 6. 通过标准

- `M-RBAC-001~004` 必须全部通过
- 不允许出现越权页面入口或越权操作入口
- 机构管理页必须保持“仅组织结构维护”边界
